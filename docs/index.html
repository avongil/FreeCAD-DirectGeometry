FreeCAD workbench · direct 2D geometry in 3D space

Direct Geometry

Mastercam X style drawing in 3D space, for FreeCAD. Draw lines, arcs, circles, rectangles and polygons straight into the model, on any plane at any depth, with no sketch and no history.

Tested on FreeCAD 26.3.0dev (weekly 2026-09-16) Version 0.1.0 · proof of concept Source github.com/avongil/FreeCAD-DirectGeometry
Proof of concept. It's a bit rough around the edges, but it works. Bug reports are welcome on the issues page.

Why

My favorite direct CAD interface is the Mastercam X style interface. It was gone after X9, but it's still loved by many! You pick a construction plane and a depth and just draw. AutoCursor snaps to ends, midpoints, centres and intersections, and a ribbon bar lets you type or lock any value while the entity follows the mouse.

FreeCAD makes you open a sketch first, and sketches live on one plane. Direct Geometry brings that ease of drawing in 3D space to FreeCAD. Every entity is a plain FreeCAD Part object, so files open anywhere. When you want a solid, Make Sketch turns the wireframe into a regular Sketcher sketch for Pad, Pocket or Extrude.

Install

Direct Geometry is a plain Python workbench. You don't need to compile anything.

  1. Download the repository from github.com/avongil/FreeCAD-DirectGeometry (Code ▸ Download ZIP) and unzip it, or git clone it.
  2. Move the folder that holds InitGui.py into the Mod folder of your FreeCAD user folder. The folder name doesn't matter, but DirectGeo is tidy.
  3. Restart FreeCAD and choose Direct Geometry in the workbench selector. To remove it, delete the folder.
<your FreeCAD user folder>/
└── Mod/
    └── DirectGeo/
        ├── InitGui.py      # registers the workbench
        ├── Init.py         # keeps geometry properties editable outside the workbench
        ├── directgeo/      # tools, snapping, Cplanes, gnomon, ribbon bars
        └── icons/

Where is my FreeCAD user folder? Open View ▸ Panels ▸ Python console and type App.getUserAppDataDir(). On Windows it is usually %APPDATA%\FreeCAD\vXX-Y, on Linux ~/.local/share/FreeCAD/vXX-Y. If there is no Mod folder yet, create it. Putting the workbench folder directly in the user folder doesn't work.

The screen

The workbench adds three bars across the top of the 3D view. They appear when you switch to Direct Geometry and hide when you leave it.

AutoCursor bar

  • Shows the live X/Y/Z of the cursor. Click X, Y or Z to lock that value. Type values and press Enter to place a point.
  • Fast point takes 2,2,3 + Enter for global X2 Y2 Z3. 2,2 is a point on the current Cplane.
  • Expressions and units work everywhere: 1in, 25.4/2. Units follow the FreeCAD document (mm by default).
  • AutoCursor picks the snap types: Origin, Point, End, Mid, Center, Quad, Intersection, Tangent, Perpendicular, Horiz/Vert and Nearest. Only limits snapping to one type for the next pick.

Ribbon bar

  • Changes with each command. Typing in a field and pressing Enter edits the live (light blue) entity.
  • The label buttons lock a value, so the entity keeps it while you move the mouse.
  • + keeps the entity and continues the command. ✔ or Esc keeps it and ends the command.

Cplanes and 2D/3D mode

The Cplane bar sets where geometry is drawn. Free clicks land on the Cplane at the Z depth, and circles, arcs, rectangles and polygons are drawn parallel to it.

CplanePlane
Top / BottomXY plane, looking down / up
Front / BackXZ plane
Right / LeftYZ plane
GviewFacing the screen, whatever the current view direction
GnomonThe plane of the Dynamic Transform gnomon, so you can draw on any 3D plane
  • MODE: 2D. Every clicked or snapped point is projected onto the Cplane at the Z depth. Snapping to existing geometry draws on top of it, at your depth.
  • MODE: 3D. Points stay exactly where they snap, so you can join geometry at different depths.
  • Typed coordinates are always used as typed. Dynamic Transform, Trim and Fillet ignore the mode.
  • Axes (F9) shows the system axes.

Dynamic Transform

The gnomon from Mastercam X4. Move, copy and rotate geometry by dragging handles, with AutoCursor snapping while you drag.

  1. Select entities, or start the command and select, then press Enter.
  2. Pick the gnomon origin, or press Enter for the centre of the selection.
  3. Click a handle, move the mouse, click again.
HandleAction
ArrowMove along U, V or W.
SquareMove in that plane.
ArcRotate about the axis.
Centre ballMove to a snapped point.
  • dU / dV / dW and Angle in the ribbon edit the last move exactly.
  • Move or Copy, with a number of copies. Angle Step and Dist Step set increments.
  • Gnomon Only repositions or re-orients the gnomon without moving geometry.
  • Cplane = Gnomon makes the gnomon's plane the drawing plane. That's how you draw 2D geometry on any plane in 3D.
  • Each entity keeps its own colour and width, and copies take theirs from the original.

Entity properties

Click an entity with no command running and FreeCAD's property view shows it. The Data tab has a Geometry group you can edit directly. Edits reshape the entity at once and can be undone.

EntityEditable properties
PointPosition (X, Y, Z)
LineStart Point, End Point, Length, Angle (XY plane)
CircleCenter, Radius, Diameter, Normal
ArcCenter, Radius, Diameter, Start Angle, End Angle, Normal (Start/End Point shown read only)

The View tab holds Line Color, Line Width, Point Color, Point Size and Draw Style.

Make Sketch

On the DG Output toolbar and at the end of the Create menu. Select coplanar entities and click it. You get a Sketcher sketch placed on their plane (any Cplane, any depth) with coincident, horizontal and vertical constraints added, ready for Part Extrude or PartDesign Pad/Pocket. The original entities are kept.

Text and curves

Drafting

No drafting dimensions and no 3D solids. Use Make Sketch and PartDesign for solids.
